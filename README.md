# neurointerface.js

[![](npm.svg)](https://www.npmjs.com/package/neurointerface)

Connect to wearable neural devices over Bluetooth from the browser or the command line.

## Install

```
$ npm install -g neurointerface
```

## Usage

```
$ neurointerface scan
```

### Mendi (fNIRS)

```
$ neurointerface read --device mendi
```
